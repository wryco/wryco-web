Wryco / Post / 1780253443 / Nextruder Plotter Color Reference

My most popular 3d model so far has been the nextruder plotter adapter for prusa printers. I've optimized it a fair bit, and I commonly use them to plot art. One difficulty I've found with making art with the plotter is color accuracy. To resolve this, I've created the scans below to source color points. There's some sampling bias present in only picking a single point, but I leave that work for future improvement. I also foresee some difficulties with sampling from scanned colors as the scanner might be color shifting
